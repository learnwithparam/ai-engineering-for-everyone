# Personal data in the office

## Data map

| Data                                  | Where it is                      | Sent to AI (yes, no) | Why                                                                                              |
| ------------------------------------- | -------------------------------- | -------------------- | ------------------------------------------------------------------------------------------------ |
| Child's name                          | Forms, Part A; register; letters | yes                  | The letter must name the right child.                                                            |
| Date of birth                         | Forms, Part A                    | yes                  | It shows the child is the right age for Year 7.                                                  |
| Home address                          | Forms, Part B                    | no                   | Only the distance is needed. The council map tool gives it.                                      |
| Parent's email                        | Forms, Part C; register; inbox   | no                   | The AI never sends mail, so it does not need it.                                                 |
| Health: an EHCP that names the school | Forms, Part D                    | yes                  | It is health data. The AI needs only yes or no, never the plan itself or why the child has one.  |
| Care status: looked-after child       | Forms, Part D                    | yes                  | It is very private. The AI needs only yes or no, and a person checks every yes with the council. |
| Notes about the child                 | Forms, Part F                    | no                   | They do not change the order, and they can hide orders to the AI.                                |

## My plan's data settings

I use the Free plan. In Settings, then Privacy, there is a choice about using my chats to improve the models. I turned it off. I only use the made-up forms, never real ones.
