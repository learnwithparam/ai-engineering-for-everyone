# The office's actions

| Action                             | Reads or changes            | Risk                                        | Approval                                             |
| ---------------------------------- | --------------------------- | ------------------------------------------- | ---------------------------------------------------- |
| Read the register                  | reads                       | low: nothing changes                        | none needed                                          |
| Read a form or an email            | reads                       | low, but the text may hold orders to the AI | none needed                                          |
| Draft a letter                     | changes: saves a draft only | medium: a wrong clause or name              | Admissions Officer reads it                          |
| Send a letter or email to a parent | sends                       | high: a family acts on it                   | Admissions Officer signs it                          |
| Withdraw a place                   | changes the register        | high: a child loses a place                 | Admissions Officer, after checking the email on file |
| Offer a place                      | changes the register        | high: the wrong child gets the place        | none, the AI follows the list                        |
| Delete a form                      | changes: removes a record   | high: it cannot be undone                   | Head teacher only                                    |
