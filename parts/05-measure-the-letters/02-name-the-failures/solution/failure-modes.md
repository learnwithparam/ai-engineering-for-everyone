# What goes wrong in the letters

I read 20 letters in batch A. 5 were marked no.

## Failure modes

| Failure mode                | Count | Pass rule                                                        |
| --------------------------- | ----- | ---------------------------------------------------------------- |
| The clause does not exist   | 1     | Does every clause number in the letter exist in the 2027 policy? |
| Does not match the register | 2     | Do the name and the status in the letter match the register?     |
| Says the AI decided         | 1     | Does the letter say only a person makes the decision?            |
| No way to appeal            | 1     | Does every waiting list letter say how to appeal?                |
