# Review of the Sortwell Admit pitch

## Claims

- "95% accurate."
- "Saves 80% of staff time."
- "Fully automatic. Sortwell Admit makes the decisions." This breaks clause 1.2 of our policy: a person makes every decision.
- "Fair by design. Our model has no bias."
- "Works with any policy."
- "Your data is stored safely in the cloud."

## What evidence would prove each

- 95%: results on a test set of real forms like ours, with the answer key, and what counts as right.
- 80%: staff time before and after at one named school, measured the same way.
- Makes the decisions: nothing can make this fine. We need a person to approve each one.
- No bias: results split by group on the same test set.
- Any policy: a test on our own 2027 policy, with the clause changes from 2026.
- Data: a contract that says where the data is kept, who sees it, and if it trains a model.

## Questions to ask

1. What does it cost per application?
2. Is there a discount for two years?
3. How much is the setup fee?
4. Is the GBP 2 per application paid every year?
5. Can we pay by the term?
6. What does the price include?

## Verdict

Not yet. The tool would make decisions, which clause 1.2 does not allow. We would only test it if a person approves every offer, and it passes our own test set first.
